## О проекте

**Chatbot for Places** — это интеллектуальный помощник для поиска мест досуга (кафе, рестораны, парки, музеи, развлечения) в Москве. В отличие от стандартных геосервисов, которые учитывают только рейтинг и географическую близость, данная система анализирует **семантическое содержание текстового запроса** и **эмоциональное состояние пользователя**.

### Ключевая идея

> Не просто «где поесть?», а «где мне будет хорошо с моим текущим настроением?»

Система решает фундаментальную проблему существующих сервисов: человеку в романтическом настроении и человеку, ищущему шумную компанию, нужны совершенно разные заведения, даже если их средний рейтинг одинаков.

## Архитектура системы

Система построена на принципе **многоканального анализа** пользовательского запроса. Каждый из четырёх специализированных модулей извлекает определённый тип информации и сопоставляет её с характеристиками заведений.

## Модули системы

### Модуль 1: Определение интенций пользователя

**Задача:** Отнести текстовое сообщение к одной из 18 категорий целевых установок в сфере досуга.

**Классы интенций:** `romantic_date`, `first_date`, `quiet_cozy`, `evening_night`, `budget_leisure`, `luxury_premium`, `view_scenic`, `outdoor_walk`, `cafe_dessert`, `active_sport`, `cultural`, `party_nightclub`, `gaming`, `relax_wellness`, `with_friends`, `with_family`, `food_search`, `general_recommendation`.

**Техническая реализация:**
- **Модель:** LaBSE (Language-agnostic BERT Sentence Embedding) — многоязычная модель, обученная на 100+ языках
- **Классификатор:** Dropout (0.4) + линейный слой (768 → 18)
- **Обучающий корпус:** 5203 синтетических примера, сгенерированных Llama 3.2
- **Метрики:** Accuracy = 0.853, Weighted F1 = 0.852

---

### Модуль 2: Экстракция атмосферно-интерьерных маркеров

**Задача:** Выделить из запроса описательные характеристики желаемой атмосферы или интерьера.

**Примеры маркеров:** «приглушённый свет», «громкая музыка», «деревянные столы», «уютно», «тихо».

**Техническая реализация:**
- **Модель:** DeepPavlov/rubert-base-cased с BIO-разметкой (O, B-AMBIENCE, I-AMBIENCE)
- **Обучающий корпус:** 2999 запросов, сгенерированных Vikhr-Nemo-12B-Instruct
- **Метрики:** Weighted F1 = 0.878, Accuracy = 0.880

**Как это работает:**
```
Запрос: "Хочу тихое место с мягкими диванами"
        ↓ BIO-разметка
Токены: [тихое: B-AMBIENCE] [место: O] [с: O] [мягкими: B-AMBIENCE] [диванами: I-AMBIENCE]
        ↓
Извлечённые маркеры: ["тихое", "мягкие диваны"]
```

---

### Модуль 3: Извлечение параметрических сущностей

**Задача:** Обнаружить конкретные, формально проверяемые требования к заведению.

**Типы сущностей:** наличие парковки, Wi-Fi, возможность бронирования, уровень цен, условия для детей, способы оплаты.

**Техническая реализация:**
- **Модель:** paraphrase-multilingual-MiniLM-L12-v2
- **Метод:** Семантическое сравнение запроса с эталонными описаниями атрибутов
- **Порог уверенности:** 0.6 косинусной близости
- **Канонизация:** 166 исходных атрибутов сведены к 136 каноническим признакам
- **Метрики:** Precision = 0.87, Recall = 0.76, F1 = 0.80

**Пример работы:**
| Запрос | Извлечённые required | Извлечённые excluded |
|--------|---------------------|---------------------|
| "Тихое место с вином и десертами, без детей" | Atmosphere_Quiet (0.76), Offerings_Wine (0.72), Dining_options_Dessert (0.68) | Children_Good_for_kids (0.71) |
| "Где можно забронировать столик, с парковкой" | Planning_Accepts_reservations (0.82), Parking_On-site_parking (0.65) | — |

---

### Модуль 4: Аффективно-поведенческий анализ

**Задача:** Определить эмоциональное состояние пользователя и желаемую стратегию совладания.

**Ключевая идея:** Разные люди по-разному проживают одни и те же эмоции. Человек в состоянии гнева может хотеть успокоиться, а может — выплеснуть энергию.

**Техническая реализация:**
- **Модель эмоций:** fyaronskiy/ruRoberta-large-ru-go-emotions (28 категорий)
- **Метод определения стратегии:** Гибридный (лемматизация + семантический поиск)
- **Матрица решений:** Для каждой пары «эмоция + стратегия» предопределён 5-мерный вектор желаемых характеристик (активность, шум, атмосфера, освещённость, заполненность)
- **Метрики:** уверенность стратегий до 0.93

**Пример работы:**
```
Запрос: "Устал на работе, хочу просто посидеть в тишине"
        ↓
Эмоция: усталость/грусть
Стратегия: спокойствие
        ↓
Желаемый профиль: низкая активность, тихий шум, уютная атмосфера, малолюдность
```

## Набор данных

### Источник данных
Данные собраны с платформы **Google Maps** с помощью инструмента [google-maps-scraper](https://github.com/gosom/google-maps-scraper).

### Объём данных
- **3157** уникальных заведений Москвы после дедупликации
- **299 028** обработанных русскоязычных отзывов
- **18** категорий заведений (парки, музеи, кафе, рестораны, развлечения и т.д.)
- **166** уникальных структурированных признаков

### Предобработка отзывов
1. Удаление пустых значений (93 221 запись)
2. Определение языка с помощью `langid` (обнаружен 91 язык)
3. Перевод иноязычных отзывов на русский язык
4. Фильтрация политически окрашенных отзывов (31 запись)
5. Удаление отзывов, состоящих только из эмодзи (1575 записей)

## Использование

### Интерфейс чат-бота

1. **Выделите область на карте** — прямоугольником или кликом по точке
2. **Напишите запрос** на естественном языке, например:
   - «Хочу тихое место с видом на парк»
   - «Ищу шумный бар с танцами для компании»
   - «Недорогой ресторан с живой музыкой, без смартфонов»
3. **Получите топ-5 рекомендаций** с указанием названия, адреса и рейтинга

### Дополнительные возможности

| Кнопка | Действие |
|--------|----------|
| **Ещё** | Показать следующие 5 рекомендаций из того же ранжированного списка |
| **Новый поиск** | Сбросить состояние сессии и начать поиск заново |
| **Не нравится** | Добавить заведение в чёрный список и исключить из будущих рекомендаций |

## Перспективы развития

- **Оптимизация производительности:** внедрение кэширования результатов, переход на платный тариф с гарантированными ресурсами
- **Расширение географии:** добавление данных о заведениях других городов
- **Мультимодальный поиск:** интеграция визуального контента (фотографий интерьеров) для поиска по изображениям
- **Улучшение гибридного метода:** доработка идентификации копинг-стратегий для повышения точности
- **A/B-тестирование:** валидация качества рекомендаций с реальными пользователями
